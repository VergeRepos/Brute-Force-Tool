## Project Overview

BruteForce Toolkit is a comprehensive, open-source educational application designed by VergeRepos for cybersecurity students and professionals to understand password attack methodologies and the importance of security policies.

## Key Features

*   **Attack Methods:** Dictionary attacks, Brute Force, and Hash Cracking (MD5, SHA1, SHA256, SHA512).
*   **Customization:** Adjustable character sets, password lengths, and 1337 speak mutations.
*   **Performance:** Real-time statistics, progress logging, and speed tracking.

## Installation

```bash
# Clone the repository
git clone https://github.com
cd Brute-Force-Tool
```

*Prerequisites: Python 3.6+ and Tkinter.*
